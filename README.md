# htr-xnglo notepad (xnglopxd)

An Android notepad app with a font picker and htrlib
(https://github.com/zawa8/htrlib) -integrated transliteration.

See CLAUDE.md for architecture, build instructions, and what's verified
vs. still a first draft (the Android app itself hasn't been built in
this environment -- only the plain-Kotlin transliteration core has).
